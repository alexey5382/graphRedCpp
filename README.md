# 🎨 Graphic Editor (C++ / SFML 3.0)

Профессиональный векторный графический редактор, написанный на **C++** с использованием библиотеки **SFML 3.0** и графического интерфейса **ImGui**. Проект реализует сложную математику трансформаций, работу с группами объектов и расширенное редактирование геометрии.

## ✨ Основные возможности

* **📐 Умное масштабирование:** Реализован алгоритм глобального пропорционального искажения (Shear), позволяющий масштабировать повернутые фигуры без потери формы.
* **🛠 Редактор узлов:** Возможность перемещать каждую вершину многоугольника индивидуально и изменять параметры каждой стороны (цвет, толщина).
* **👥 Группировка:** Объединение фигур в группы (Ctrl+G), вложенное выделение (через Ctrl) и управление общим якорем группы.
* **🖊 Режим рисования:** Интерактивное создание ломаных и многоугольников с поддержкой привязки углов через Shift.
* **📋 Инспектор свойств:** Полный контроль над цветом заливки, обводкой, вращением и координатами через панели ImGui.
* **💾 Сохранение:** Поддержка сохранения и загрузки всей сцены в текстовый файл `scene_save.txt`.

## 🚀 Технологии

* **Язык:** C++ (стандарт 17 и выше).
* **Графика:** [SFML 3.0](https://www.sfml-dev.org/) (Внимание: проект использует новейшую версию 3.0.0).
* **Интерфейс:** [Dear ImGui](https://github.com/ocornut/imgui) + [imgui-sfml](https://github.com/SFML/imgui-sfml).

## 📦 Установка и сборка

Проект разработан в **Visual Studio 2022**. Поскольку библиотеки SFML зависят от версии компилятора, заголовочные файлы и `.lib` файлы необходимо загрузить самостоятельно.

### 1. Подготовка
* Установите [Visual Studio 2022](https://visualstudio.microsoft.com/ru/vs/) (обязательно выберите рабочую нагрузку "Разработка классических приложений на C++").
* Загрузите **SFML 3.0** с [официального сайта](https://www.sfml-dev.org/download.php) (версия *MSVC 2022 64-bit*).

### 2. Настройка проекта в Visual Studio
1.  Склонируйте репозиторий и откройте `Lab3.sln`.
2.  Нажмите правой кнопкой мыши на проект **Lab3** -> **Свойства (Properties)**.
3.  **Заголовочные файлы:** Перейдите в **C/C++** -> **Общие** -> **Дополнительные каталоги включаемых файлов** и укажите путь к папке `SFML-3.0.0/include`.
4.  **Библиотеки:** Перейдите в **Компоновщик** -> **Общие** -> **Дополнительные каталоги библиотек** и укажите путь к папке `SFML-3.0.0/lib`.
5.  **Ввод:** Перейдите в **Компоновщик** -> **Ввод** -> **Дополнительные зависимости** и добавьте (для конфигурации **Debug** добавьте суффикс `-d`):
    * `sfml-graphics.lib` (или `sfml-graphics-d.lib`)
    * `sfml-window.lib` (или `sfml-window-d.lib`)
    * `sfml-system.lib` (или `sfml-system-d.lib`)

### 3. Динамические библиотеки (DLL)
Все необходимые `.dll` файлы уже находятся в корне репозитория.
* После сборки проекта скопируйте все файлы `.dll` из корня репозитория в папку с вашим `.exe` (обычно `x64/Debug` или `x64/Release`).

### 4. Шрифты
Программа использует системный шрифт `C:/Windows/Fonts/arial.ttf` для отображения кириллицы. Убедитесь в его наличии или измените путь в `main.cpp`.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
| :--- | :--- |
| **Ctrl + G** | Сгруппировать выделенные объекты |
| **Delete** | Удалить выбранные объекты |
| **Shift** | Мульти-выделение или привязка угла при рисовании |
| **Ctrl** | Выбор отдельной фигуры внутри группы |
| **Enter / Tab**| Завершить рисование (разомкнутая / замкнутая фигура) |
| **Escape** | Отмена текущего рисования |

## 📐 Особенности реализации

* **Система якорей:** Центр вращения можно перемещать отдельно от фигуры без её визуального смещения.
* **Bake Rotation:** Функция "запекания" позволяет сбросить угол поворота в 0, сохранив текущую форму фигуры в мировых координатах.
* **Internal Stroke:** Обводка фигур рисуется строго **внутрь**, что обеспечивает идеальное совпадение визуальных границ с рамкой выделения.
